# thuroi0787.github.io

Personal site of Ruoyu (Roi) Zhao, built with Jekyll on GitHub Pages.

Content lives in `_data/`:

| File | What it holds |
| --- | --- |
| `profile.yml` | Sidebar card, links, About text, research focus |
| `research.yml` | The four research theme cards |
| `news.yml` | News items (newest first) |
| `publications.yml` | Papers; `featured: true` gives a large card with a figure |
| `experience.yml` | Experience and education timelines |
| `misc.yml` | Honors, teaching, reviewing |

Paper figures go in `assets/img/papers/`, logos in `assets/img/logos/`.

Local preview: `bundle exec jekyll serve`, then open http://localhost:4000.
